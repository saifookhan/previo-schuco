# Not built yet

Things testers should **not** report as bugs — they are known and planned:

- **Dashboard numbers are placeholders** — the cards and "Recent quotes" on *Dashboard* show sample
  values, not your real data.
- **Invoice** page is an early design replica, not connected to quotes.
- Quote status workflow (draft → sent → accepted / rejected) — every quote stays *Draft*.
- Editing a quote's header, deleting a whole quote, duplicating a whole quote.
- Editing characteristic ↔ line relations without the Excel import.
- Reporting, notifications, print templates, export.
- Automated backups, monitoring and error tracking (infrastructure).

# PREVIO — testing documentation

PREVIO is a multi-company platform for **window and door quotes (preventivi)**. Manufacturers publish
product catalogs ("product families"), share them with suppliers at a default discount, and suppliers
build priced quotes from them and download the quote as a PDF.

This site is for **testers and the team**: where to open the app, which demo users to log in with,
where invite/reset emails land, and what each feature does.

# URL

I link in questa pagina puntano all'ambiente per cui è stata generata questa documentazione.

## Servizi

| Servizio | Questo ambiente | Locale (`pnpm dev` + `docker compose up -d`) |
|---|---|---|
| App web | <AppLink /> | `http://localhost:3000` |
| Mailpit (casella email) | <AppLink to="mailpit" /> | `http://localhost:8025` |
| API | — (l'app la chiama tramite le proprie rotte `/api/*`; pubblica è solo la documentazione API qui sotto) | `http://localhost:3001` |
| Documentazione API (Swagger UI) | <AppLink path="/docs" /> | `http://localhost:3001/docs` |
| Specifica OpenAPI | <AppLink path="/openapi.json" /> | `http://localhost:3001/openapi.json` |
| Health check API | — | `http://localhost:3001/health` |
| Questa documentazione | — | `http://localhost:3002` (`pnpm --filter @schuco/docs dev`) |

## Pagine dell'app

Gli URL non contengono la lingua — la lingua (italiano di default, inglese, tedesco) si sceglie nell'app.

### Pubbliche

| Pagina | URL |
|---|---|
| Login (+ accesso demo) | <AppLink path="/login" /> |
| Password dimenticata | <AppLink path="/forgot-password" /> |
| Imposta password (dal link nell'email di invito / reset) | `/set-password?token=…` |

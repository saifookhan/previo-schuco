# Non ancora realizzato

Cose che i tester **non** devono segnalare come bug — sono note e pianificate:

- **Gli utenti attivi nella dashboard sono un segnaposto.** Preventivi aperti, pipeline, conversione e preventivi recenti
  usano la variante che ogni preventivo segna come finale.
- Eliminare un preventivo in modo definitivo. **Archivia** lo nasconde finché il filtro Archiviati è acceso.
- Modifica delle relazioni caratteristica ↔ linea senza importare l'Excel.
- Report, notifiche, modelli di stampa, esportazione.
- Backup automatici, monitoraggio e tracciamento errori (infrastruttura).

# Non ancora realizzato

Cose che i tester **non** devono segnalare come bug — sono note e pianificate:

- **I numeri della dashboard sono segnaposto** — le card e "Preventivi recenti" nella *Dashboard*
  mostrano valori di esempio, non i tuoi dati reali.
- La pagina **Invoice** è una prima replica grafica, non collegata ai preventivi.
- Flusso di stato del preventivo (bozza → inviato → accettato / rifiutato) — ogni preventivo resta *Bozza*.
- Modifica dell'intestazione del preventivo, eliminazione e duplicazione dell'intero preventivo.
- Modifica delle relazioni caratteristica ↔ linea senza importare l'Excel.
- Report, notifiche, modelli di stampa, esportazione.
- Backup automatici, monitoraggio e tracciamento errori (infrastruttura).
